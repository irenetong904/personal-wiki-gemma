# Agent Building Platforms

Agent Building Platforms facilitate the creation and management of AI agents, allowing users to define and deploy complex, automated workflows. These platforms incorporate features like agent builders, long-horizon planning, and the ability to translate natural language instructions into functional agents.

## Details
- Decagon's Agent Operating Procedures (AOPs) allow teams to define and iterate agent behavior using natural language, turning SOP-like instructions into inspectable, versionable workflows. ([[raw/Decagon - company-research.md|Decagon - company-research.md]])
- Sierra's Ghostwriter is an 'agent-building agent' that converts SOPs, transcripts, or plain-English goals into a production agent. ([[raw/Sierra - company-research.md|Sierra - company-research.md]])
- Harvey AI offers an Agent Builder, enabling the creation of purpose-built agents, and launched the first certified AI agents in legal (AIUC-1 certification). ([[raw/Harvey AI - company-research.md|Harvey AI - company-research.md]])
- Clay offers Clay MCP + Agent plugin CLI/API to integrate Clay into coding agents and provides features like real-time intent signaling. ([[raw/Clay - company-research.md|Clay - company-research.md]])
- Sierra's Horizon feature focuses on long-horizon agents capable of planning multi-step outcomes over days or months while maintaining memory. ([[raw/Sierra - company-research.md|Sierra - company-research.md]])
